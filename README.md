# MARVEL AI: Choose Your Avenger 🦸‍♂️✨

A cinematic, interactive **Marvel-themed AI character roulette web application** powered by Next.js, Framer Motion, HTML5 Canvas, Web Audio API, and Google Gemini API.

## 🌟 Key Features

- **Avengers Command Center Aesthetic**: Deep charcoal UI, glassmorphism card panels, interactive HTML5 particle canvas background, and Web Audio API sci-fi sound effects.
- **Weighted Superhero Roulette Wheel**:
  - Hulk: 16%
  - Captain America: 16%
  - Hawkeye: 16%
  - Black Widow: 16%
  - Spider-Man: 16%
  - Black Panther: 16%
  - **Iron Man: 4% (Rare Legendary)**
- **Iron Man "LEGENDARY UNLOCK"**: Golden arc-reactor energy burst, particle confetti celebration, and victory audio fanfare when hitting the 4% drop rate.
- **Gemini-Powered AI Chatbot**: Secure Next.js server route (`/api/chat`) with Google Search Grounding and dynamic roleplay system prompts for each hero persona.
- **Mission History**: LocalStorage persistence tracking past unlocked heroes, timestamps, spin counts, and stats.

## 🚀 Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/sahilhinduja04/MARVEL.git
cd MARVEL
npm install
```

### 2. Configure Environment
Create a `.env.local` file in the root directory:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
